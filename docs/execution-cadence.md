# Execution Cadence

## Working Rhythm

1. Daily
- 15-minute standup:
  - Yesterday progress
  - Today focus
  - Blockers
- Update backlog item statuses.

2. Weekly
- Weekly planning (60 minutes):
  - Prioritize next sprint tasks
  - Confirm dependencies and owners
- Weekly review (30 minutes):
  - Demo completed increments
  - Track risks and decisions

3. Biweekly
- Milestone review:
  - Progress against phase exit criteria
  - Scope or timeline adjustments
  - Go/No-Go for next phase

## Documentation Rule

- Any major technical or product decision must be logged in `docs/ADR.md` within 24 hours.

## Blocker Rule

- If a task is blocked for more than 1 business day, escalate and add mitigation steps in backlog notes.
