# Path Decision Matrix v1

## Paths

1. Path A: Distribute through existing providers
2. Path B: Build own provider infrastructure

## Scoring (1-5)

| Factor | Weight | Path A | Path B | Notes |
|---|---:|---:|---:|---|
| Time to market | 5 | 5 | 2 | Existing providers are faster |
| Upfront cost | 4 | 4 | 2 | Own provider is more expensive |
| Regulatory complexity | 5 | 4 | 1 | Own provider carries higher burden |
| Strategic control | 3 | 3 | 5 | Own provider gives full control |
| Scale upside | 3 | 4 | 5 | Own provider can scale portfolio |

## Recommendation (Current Stage)

Choose **Path A** first for faster launch, then evaluate Path B after first revenue cycle.
