# 01 Program Setup

## Goal
Create project governance, initial technical boundaries, and decision records so execution is consistent.

## Inputs

- `ROADMAP.md`
- Your current assumptions

## Tasks

1. Define project identity placeholders:
   - Working studio name
   - Working game codename
   - Versioning strategy (`v0.1.0` etc.)
2. Define repository structure:
   - `docs/`
   - `math/`
   - `backend/`
   - `client/`
   - `qa/`
   - `infra/`
3. Create decision log file (`docs/ADR.md`):
   - Record major decisions and reasons
4. Define team roles:
   - Product/Feature owner
   - Math designer
   - Backend engineer
   - Frontend engineer
   - QA
   - Compliance/legal owner
5. Define operating cadence:
   - Weekly planning
   - Daily progress log
   - Milestone review every 2 weeks
6. Define security baseline:
   - Secrets handling policy
   - Branch protections
   - Dependency scanning policy

## Deliverables

- Project folder skeleton
- `docs/ADR.md`
- Team responsibility matrix
- Execution cadence doc

## Exit Criteria

- Everyone knows who owns each workstream.
- Decision logging is active.
- Repo structure supports all upcoming phases.
