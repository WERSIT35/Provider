# 11 Commercial Strategy (Provider Deals vs Own Provider Path)

## Goal
Choose and execute the fastest path to revenue.

## Path A: Offer Game to Existing Providers

### Advantages

- Faster distribution
- Existing operator network
- Less operational complexity

### Requirements

- Certified game package
- Integration kit
- Support and SLA readiness
- Commercial terms (rev share / fixed fees)

## Path B: Build Own Provider Layer

### Advantages

- Full control of roadmap and economics
- Ability to distribute multiple games later

### Costs/Risks

- Higher legal/compliance burden
- Larger infra and support responsibilities
- Longer time to revenue

## Tasks

1. Build decision matrix:
   - Time-to-market
   - Cost-to-launch
   - Regulatory complexity
   - Strategic control
2. Provider outreach kit:
   - One-page game brief
   - Demo video / playable link
   - Certification proof package
3. Commercial readiness:
   - Contract templates
   - Revenue reporting model
   - Support model
