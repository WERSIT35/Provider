# Integration Kit Checklist v1

## Package Contents

1. Game overview
- Theme, feature summary, RTP profiles

2. Technical docs
- API specification
- Error code list
- Callback/retry behavior

3. Compliance and certification docs
- Rules draft
- Math package summary
- Security controls summary

4. Testing assets
- Sandbox endpoint URLs
- Test credentials
- Sample request/response payloads

5. Operations docs
- Incident contact
- Support hours
- SLA expectations

## Delivery Format

- Zip package + secure shared link
- Versioned by date and build ID
