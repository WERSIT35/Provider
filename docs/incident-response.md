# Incident Response Plan v1

## Severity Levels

1. Sev-1
- Financial integrity or broad outage risk.

2. Sev-2
- Degraded core functionality with workaround.

3. Sev-3
- Limited non-critical impact.

## Response Steps

1. Detect and acknowledge.
2. Assign incident commander.
3. Contain impact.
4. Restore service.
5. Validate correctness (wallet and spin integrity).
6. Publish post-incident report in 48 hours.

## Must-Have Checks for Slot Incidents

- Any missing or duplicate ledger records?
- Any unresolved spins?
- Any unauthorized config changes?
- Any RTP or feature behavior anomalies?
