# 08 Provider Integration Readiness

## Goal
Prepare technical and operational package required for provider onboarding.

## Tasks

1. Provider target shortlist (top 5 initially):
   - API model fit
   - Geography fit
   - Commercial terms fit
2. Build adapter layer:
   - Normalize wallet/session APIs
   - Handle provider-specific auth and callbacks
3. Prepare integration kit:
   - Technical API documentation
   - Error code matrix
   - Certification package references
   - Demo environment access info
4. Sandbox testing:
   - Session start/stop
   - Bet/win settlement
   - Bonus flows
   - Timeout/failure recovery
5. Operational readiness:
   - SLA expectations
   - Monitoring per provider
   - Support escalation contacts

## Deliverables

- `docs/provider-targets.md`
- `docs/provider-api-mapping.md`
- `docs/integration-kit.md`
- `docs/sandbox-test-results.md`

## Exit Criteria

- At least one provider sandbox passed.
- Integration docs complete and shareable.
- Commercial discussion package ready.
