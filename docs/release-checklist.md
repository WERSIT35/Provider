# Release Checklist v1

## Pre-Release

1. QA exit criteria met
2. Security checks passed
3. Approved math config selected
4. Rollback package prepared
5. Monitoring dashboards verified

## Release Window

1. Deploy backend
2. Deploy client
3. Run smoke tests
4. Validate live settlement and telemetry

## Post-Release

1. Monitor error/latency for 24h
2. Confirm no settlement anomalies
3. Publish release report
