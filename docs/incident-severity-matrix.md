# Incident Severity Matrix v1

| Severity | Definition | Example | Response Target |
|---|---|---|---|
| Sev-1 | Critical business/security impact | Settlement corruption, full outage | Immediate |
| Sev-2 | Major degradation | High error rate, major feature broken | < 30 min |
| Sev-3 | Moderate issue | Isolated feature defect | < 4 hours |
| Sev-4 | Minor issue | Cosmetic/UI low impact | Next cycle |

## Ownership

- Incident commander rotates weekly.
- Sev-1 requires executive and compliance visibility.
