# 09 QA, Certification, and Lab Submission

## Goal
Pass internal QA and external certification needed for regulated distribution.

## Tasks

1. QA strategy:
   - Functional tests
   - Math consistency tests
   - Regression tests
   - Load/stability tests
2. Test planning:
   - Base game scenarios
   - Bonus edge cases
   - Currency/bet boundary tests
   - Interrupted session recovery
3. Automation:
   - API integration tests
   - Deterministic replay tests for known outcomes
4. Certification prep:
   - Finalized rules docs
   - Math package
   - RNG and security documents
   - Build hash/version records
5. Lab cycle management:
   - Submit artifacts
   - Track findings
   - Patch and resubmit

## Deliverables

- `qa/test-plan.md`
- `qa/test-cases.md`
- `qa/regression-checklist.md`
- `qa/certification-package-index.md`

## Exit Criteria

- Critical defects closed.
- Certification findings resolved.
- Release candidate approved for production launch.
