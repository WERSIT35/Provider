# LiveOps KPI Dashboard Spec v1

## Product KPIs

- Spins per day
- Average bet size
- Session length
- Bonus trigger rate
- Win distribution bands

## Financial Integrity KPIs

- Debit/credit mismatch count
- Unresolved spin count
- Duplicate settlement events

## Technical KPIs

- API p95 latency
- Error rate
- Client crash rate

## Alert Threshold Examples

- Settlement mismatch > 0 triggers immediate alert
- API error rate > 1% over 5 min triggers incident review
