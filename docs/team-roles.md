# Team Responsibility Matrix

## Core Roles

1. Product Owner
- Owns game direction, priorities, and feature acceptance.

2. Math Designer
- Owns paytable, reel strips, RTP, volatility, simulation outputs.

3. Backend Engineer
- Owns session, wallet, settlement, audit logging, integration APIs.

4. Frontend Engineer
- Owns slot client UX, animation pipeline, and client-backend state flow.

5. QA Lead
- Owns test strategy, automation coverage, and release quality gates.

6. Compliance/Legal Owner
- Owns jurisdiction requirements, certification package completeness, and legal signoff.

7. DevOps/SRE
- Owns environments, deployment safety, monitoring, and incident response operations.
