# UI Flow v1

## Main Screens

1. Loading screen
2. Game screen
3. Rules/info modal
4. Error/reconnect modal

## Main Flow

1. App boot
2. Session initialization
3. Enter game idle state
4. Player sets bet and spins
5. Show results and updated balance
6. Enter/exit bonus when applicable

## Controls

- Spin
- Bet up/down
- Autoplay (if legally allowed)
- Sound
- Rules/Info

## Mandatory Display Fields

- Balance
- Current bet
- Last win
- RTP disclosure
- Game version
