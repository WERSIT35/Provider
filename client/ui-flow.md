# UI Flow v2 (Rebuilt Client)

## Main Flow

1. App boot.
2. Session init.
3. Idle state with bet controls.
4. Spin/buy feature action.
5. Server result arrives.
6. Reels animate and settle.
7. Balance/stats/payload panels refresh.
8. Bonus autoplay flow when free spins are active.
9. Simulation stream runs independently from game spin loop.

## Core Panels

- Hero
- Game Column
- Side Column (Live + Simulation)
- Details Row (Result + Info)
