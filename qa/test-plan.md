# QA Test Plan v1

## Scope

- Base game, bonus game, session lifecycle, settlement integrity.

## Test Types

1. Functional
2. Integration
3. Regression
4. Performance
5. Recovery and resilience

## Environments

- Local dev
- Staging
- Provider sandbox

## Entry Criteria

- Feature specs frozen
- API contract stable
- Test data available

## Exit Criteria

- No open critical defects
- High-severity defects accepted or fixed
- Regression pass complete
