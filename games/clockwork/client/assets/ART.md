# Clockwork Menagerie: art and fonts

## Images (`art/`)

Every image here was generated by the game's owner with Google Gemini from prompts written
for this game (October 2026), then cut out and resized for the client. No image was traced
or copied from another game, provider or brand, and no prompt named one.

| File | What it is | Made from |
|---|---|---|
| `bg_base.webp` | The toymaker's workshop by lamplight (base game) | one generated image |
| `bg_night.webp` | The same workshop at night, teal lamps (free spins) | one generated image |
| `logo.webp` | The "Clockwork Menagerie" sign | one generated image, background removed |
| `owl.webp`, `fox.webp`, `hare.webp`, `tortoise.webp` | The four brass animals (high symbols) | generated symbol sheets, cut apart |
| `gear.webp`, `spring.webp`, `nut.webp`, `screw.webp`, `wrench.webp` | The workbench parts (low symbols) | generated symbol sheets, cut apart |
| `key.webp` | The wind-up key (wild) | generated symbol sheet, cut apart |
| `wild_reel.webp` | A wound reel: the brass column the key turns its reel into | one generated image, background removed |
| `box.webp`, `box_open.webp` | The music box (scatter), closed and open (when it counts) | one generated sheet, cut apart |

Cutting: the flat backdrop was removed with a flood fill from the edges and a soft alpha
edge; each object was trimmed and centred on a transparent square (symbols 320 px, the wild
column 286 x 1100 px), saved as WebP. The board, its smoked glass, the brass rim, the wound
reel's glow, gauge and multiplier badge, the lines and the amount tags are drawn in code.

## Fonts (`fonts/`, SIL Open Font License 1.1, licence files beside them)

- Spectral SC SemiBold: panel titles (`--display`).
- Alegreya Sans Bold: interface text (`--ui`).
- Barlow Condensed SemiBold: amounts, multipliers and tags (`--num`).

Latin subsets from the Fontsource packages (`@fontsource/*` 5.3.0).
